Navigation

Household tab order

One order for everyone. Home always comes first; Admin stays last for admins.

Home

Home settings

Control whether system status is visible to members and the house-wide account. Admins can always see it.

Lists

Lists settings

Household settings for shopping, to-do lists, and chores will be configured here. List actions remain in the Lists tab.

Recipes

Recipes settings

Household recipe limits and any future import settings will be configured here. Recipe editing remains in the Recipes tab.

Event budgets

Calendar limits

Monthly limits can be set from 7 to 512. Repeating occurrences count.

Calendar

Calendar retention

Keep the current calendar year and up to ten previous years available for browsing.

Current year plus 3 previous years retained.

Archive files can be downloaded from Admin settings. Reducing retention tries to export each affected year first; a failed export leaves its events in place.

Archive folder/home/homehub/.local/share/homehub/calendar-archives/Example shown; the app displays the resolved folder beside its configured database.

Weather

Weather settings

Set the household town or postal code, forecast length, units, and whether outbound weather access is enabled.

RSS

RSS settings

Manage house-wide feeds and outbound RSS access. Each person manages their own feeds in the RSS tab.

Games

Games settings

Household game settings will live here. Daily puzzles and scoreboards remain in the Games tab.

Chat

Chat settings

When local chat is enabled, installed model selection, prompt limits, and queue settings will live here. The Chat tab remains hidden until enabled.

Shared display

House-wide access

The house-wide login can see shared content and play games. Its scores stay off leaderboards.

Privacy note
Admins can view all household content, including private chats.
