Admin controls

Only one request runs at a time. Admin requests take priority; users see their queue position. The local model service stays on this device. The provider interface can support an optional remote provider later; it would be off by default and clearly disclose when prompts leave the home.

Database tools, if enabled, will use only information this user can access and will require confirmation before changes.
